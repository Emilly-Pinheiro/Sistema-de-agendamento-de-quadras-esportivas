# Projeto-Estudo-Full-Stack

Aplicação web para cadastro de jogadores, quadras e reservas de horários esportivos.

## Objetivo

Criar um sistema de agendamento para quadras esportivas permitindo  cadastrar jogadores e quadras, como também gerenciar reservas e consultar horários esportivos.

## Funcionalidades planejadas

- Cadastro de jogadores;
- Cadastro de quadras;
- Cadastro de reservas;
- Validação de conflitos de horários;
- Visualização da agenda;
- Edição e exclusão de reservas;
- Landing page;
- Filtros de consulta (Opicional);
- Autenticação, (Opicional).

## Tecnologias planejadas

### Backend

- Node.js;
- Express;
- Prisma ORM;
- PostgreSQL.

### Frontend

- React;
- Vite;
- React Router;
- CSS.
